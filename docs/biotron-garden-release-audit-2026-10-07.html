Калибровка становится готовой только после ответа устройства с совпадающим nonce. Старые нотные подсказки не заменяют этот ответ; при отсутствии подтверждения ожидание заканчивается и предлагает проверить контакты и прошивку. Добавлена регрессия для позднего READY после таймаута.

Строгий QA-режим возвращает ненулевой результат при пропущенных проверках, сохраняет хеши входных файлов и прекращает прогон с INTERRUPTED при Ctrl-C. Пропуски в исходном JSONL не переписаны в PASS.

Найдена проблема выпуска: общий запрет iframe мешал бы Garden. Pages worker разрешает встраивание только /garden/scene.html с того же origin и сохраняет ограничения остальных страниц. Проверены unit-контракт и реальная загрузка сцены на локальном стенде с этим worker. Особенности обработки заголовков сверены с документацией Cloudflare; живой Pages deployment ещё не проверен.

Компоненты Garden и обработчик звуковой сессии вынесены в отдельные чанки. Play укладывается в прежний бюджет: 25 414 gzip-байт при лимите 25 KiB. Остались прежние предупреждения размера основного entrypoint и Elementary runtime.

Что ещё блокирует выпуск

  1. Разрешение автора на коммерческое использование Garden и панорамы не установлено. Исходник автора проверен 7 октября; права остаются отдельным gate. Уведомление React Bits MIT + Commons Clause сохранено, условия выпуска требуют проверки.
  2. Нет подтверждённой записи через системный directory picker браузера. Проверка файла и BOOT прошли; подменять этот результат native flash нельзя.
  3. Полный MIDI/Play-путь на точном финальном JS-кандидате не завершён: новый origin ждёт системного разрешения. Реальное устройство проверялось на интеграционной сборке; изменения после неё не затрагивали синтез или протокол калибровки.
  4. На старом origin PWA продолжала отдавать предыдущий app.7132d5f8.js после reload и закрытия контролируемой вкладки. Чистый origin отдаёт финальные файлы. Причина удержания клиента/worker не установлена; upgrade acceptance остаётся открытым.
  5. Нужны физический Android, проверка fallback на браузерах без WebGPU, visual reduced-motion, независимое подтверждение слышимости и длительный soak.
  6. Живой Pages/D1 logger не проверен. Локальный worker намеренно возвращает 503 без SESSION_EVENTS; это не PASS доставки телеметрии. UI Copy diagnostics показал Copied, но адаптер clipboard вернул старый packet другой сессии — проверка содержимого INCONCLUSIVE.

Release_ready=false. Main и пользовательский сайт не обновлялись. Рекомендованный следующий допуск: закрыть эти пункты на одном закреплённом candidate и сохранить evidence для каждого обязательного требования.

Как повторить браузерные регрессии

Новый scripts/build-browser-qa-harness.py --output /private/tmp/новая-папка извлекает точные test bodies из существующих скриптов и записывает source manifest. Затем node /private/tmp/новая-папка/build.cjs собирает стенд установленным webpack. Открыть его через CUA: Run sound levels; Seed preset fixture; reload; Verify presets after reload. Браузер из shell не запускается.

scripts/serve-biotron-qa-worker.mjs dist 49298 обслуживает локальные assets через настоящий Pages worker, без удалённой базы и публикации. Программный прогон: python3 scripts/run-biotron-qa.py --output /private/tmp/новые-логи --require-complete.
