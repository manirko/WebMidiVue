Проверь первое действие

  1. Открой сайт кнопкой выше. Запиши компьютер, браузер и USB-связку.
  2. Подключи растение. Нажми Start listening: измерение, затем музыка.
  3. Нажми Stop & release:10 секунд должно быть тихо.
  4. Нажми Start снова. Запиши, вернулась ли музыка.

Claude ведёт по одному действию и сохраняет первый отказ до Retry.

Python3.10+, Node20+, установленный Chrome/Edge. Doctor ничего не устанавливает.

Запусти автопроход на ПК

py -3 tester.py verify
py -3 tester.py doctor
py -3 tester.py autotest --browser chrome --firmware

Смотри текущий этап, шаг и прошедшие секунды в терминале. После отказа сохрани first-fault. Подтверди закрытие собственных процессов до новой команды.

На Mac: python3 вместо py -3. MIDI и диск имитируются.

Чтобы проверить один этап:

py -3 tester.py autotest --browser chrome --phase sound
py -3 tester.py autotest --browser chrome --phase settings
py -3 tester.py autotest --browser chrome --phase firmware

Частичный PASS относится только к указанному этапу.

Автотест не прошивает прибор. Реальный звук и USB проверяются вручную.

Проверь телефон отдельно

Освободи порт на компьютере. Открой эту же HTTPS-ссылку на телефоне.

Запиши OS, browser/MIDI-app и adapter. Следуй W13 из полного плана.

Настройки проверяй со своим backup и возвратом после каждого изменения.

BOOT, установка прошивки и rollback требуют отдельного допуска. Internal111 не включён.

py -3 tester.py bundle
