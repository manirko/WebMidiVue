Browser help

Allow instrument access

MIDI permission lets this site receive notes from your instrument.

If access was blocked, the browser may stop showing the permission request.

Choose your browser below. Change the permission for this site, then try connecting again.

Chrome / Chrome Beta / Chromium
  1. Open the controls beside the page address, then Site settings.
  2. Find MIDI devices and allow this site to use them.
  3. If asked to control MIDI devices, allow that permission too.

Biotron requests this additional permission for device messages, also called SysEx. Chrome instructions.

Microsoft Edge
  1. Open the site information control beside the page address.
  2. Open Permissions for this site or Site permissions.
  3. Find MIDI devices and allow this site.

Menu wording can vary by version. Edge site permissions.

Brave
  1. Open the controls beside the page address, then Site settings.
  2. Find MIDI devices or MIDI device control & reprogram.
  3. Allow this site, then return to Play.

Brave site permissions.

Opera / Opera GX
  1. Open Settings → Privacy & security → Site settings → MIDI devices.
  2. Allow sites to ask for MIDI access if requests are blocked.
  3. Return to Play and allow the request for this site.

These are Opera's documented controls. Biotron on Opera GX still needs a separate device test. Opera MIDI instructions.

Vivaldi
  1. Open Site info → Site Settings beside the page address.
  2. Find the MIDI permission and allow this site.
  3. Return to Play and try connecting again.

If no MIDI permission appears, try Chrome or Edge. Vivaldi website permissions.

Firefox
  1. Open the permissions icon beside the page address.
  2. Remove a saved MIDI denial, then try connecting again.
  3. Firefox may request a site permission add-on for device access.

This website's USB operation in Firefox still needs a real device test. Use Chrome or Edge if access remains blocked. Firefox permission controls · Site permission add-ons.

Built-in browser in ChatGPT / Codex
  1. Check MIDI permissions for this page in the built-in browser's controls.
  2. Check the website permission indicator beside the page address.
  3. Allow Use your MIDI devices and, if requested, Control and reprogram your MIDI devices.

Controls can differ between app versions. These permission labels exist in the installed app. If you cannot find them, open this page in a separate Chrome or Edge window. Built-in browser help.

No MIDI option / Safari / iPhone or iPad

If Play says this browser cannot hear your device, use Chrome or Edge on a computer.

Changing permissions cannot add a missing MIDI feature. Computer keyboard play can still work.

USB operation needs a separate test for each browser and device. Instructions here do not certify compatibility.

After changing permission: return to Play and press Start listening again.

If access is still blocked, reload the page and retry. Reloading stops sound.

Managed browsers may prevent permission changes. Ask the administrator or use another browser.
